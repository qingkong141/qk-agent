- 当前不能按实际权限控制调用外部设备操作，因为业务服务暂无。原AI项目临床/输液工具有TODO，应在真实业务对接前避免用来证明操作成功。

## 服务端接口

全部要求AI后台Bearer令牌或现有API Key认证；API Key必须同时提供 `X-End-User-ID`。

| 方法 | 路径（相对/api/v1） | 功能 |
|---|---|---|
| GET | /studio/artifacts | 当前用户配置列表 |
| POST | /studio/artifacts | 新建配置，返回revision=1 |
| PUT | /studio/artifacts/{id} | 更新配置，必须提供expected_revision |
| POST | /studio/artifacts/{id}/publish | 发布应用快照，必须提供expected_revision |
| GET | /studio/artifacts/{id}/published | 读取当前发布版；未发布/已停用返回404 |
| POST | /studio/artifacts/{id}/unpublish | 停用当前发布版，保留草稿 |

配置请求：`{name, kind, config, expected_revision?}`，kind为mapping、pipeline、application。
版本不匹配返回409；校验失败返回422；不属于当前用户返回404。不要在错误时向用户显示保存成功。
