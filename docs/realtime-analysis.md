# 实时分析后台

`/api/v1/studio/realtime` 提供账号隔离的配置 CRUD、启动、停止和设备数据上报。配置必须为唯一输入到输出的完整单链，最多20节点，算子为过滤、聚合、补齐、恒值检测、极值检测、频率对齐。

`POST /{id}/ingest` 接受 `{"rows":[{"deviceId":"INF-001","time":"2026-09-27T04:00:00Z","value":61}]}`。value仅接受有限数值或null；未携带时区的时间按医院时区UTC+8解释。需 CurrentUser 认证，任务必须运行中且来源为push。

每批最多1,000点，按设备编号+时间覆盖/去重，以最新事件时间推进窗口。窗口最多5,000点；聚合按设备分桶平均非空值，频率对齐补入空桶，填充只处理null，恒值检测在当前窗口内连续计数，极值按设备当前窗口计算。收到新数据后重新计算窗口，空闲不按当前时钟清空。

配置修改需要停止任务并传expected_revision，更新后清空旧运行数据。无效输入返回422而不修改结果；运行时超限/计算异常置error并保留上次成功结果。操作通过数据库写锁串行化同一任务更新，结果与窗口同事务保存。

平台模式需要在backend/.env设置 `PLATFORM_DEVICE_BASE_URL` 为设备服务/api根地址。后台使用启动请求的X-Platform-Token访问固定 `/InfluxDb/GetDatas`，不存储凭据。5～300秒轮询，分页最多1,000条；解析app/data/values中的指标为标准value。空数据更新检查时间，错误停止并展示原因。单进程最多20个读取任务，页面关闭不影响读取。启动服务时将历史running平台任务置stopped，要求重新登录启动；push任务保留状态。运行uvicorn时限单worker，多进程任务调度留待部署阶段。

验证：`venv\Scripts\python.exe scripts/test_realtime_api.py`。测试使用内存数据库，覆盖窗口、算子、API生命周期、权限、失败保留、后台轮询及重启处理。254接口与浏览器联调已验证，保留测试数据。
