# 语义转换器第一版

入口：现有后台左侧「可视化工作台 → 语义转换器」。开发预览地址：http://localhost:5187/studio/mapping。

本轮只改造语义转换这一项，没有继续扩展语法转换、插件部署或其他投标模块。

## 已实现

- 转换器列表：名称搜索、源模型、目标模型、规则方式、保存版本号、编辑和测试入口。
- 模型选择：选择演示模型或已保存转换器中的模型；通过表格配置字段标识、中文名称、类型、单位、必填状态。
- 可视化映射：使用 AntV X6 拖线，点击目标字段或连线配置规则；也可通过下拉框建立连接。
- 转换规则：直接映射、倍率与偏移、状态对应、未取到值时的默认值。
- 手工脚本：采用 JSONata，可从连线生成脚本后修改，统一通过独立 Worker 执行，具有执行超时和结果大小限制。
- AI辅助：后台连接 DeepSeek 在线模型，生成候选 JSONata 脚本，用户应用后在同一测试引擎执行。只发送物模型、规则和文字要求，不发送输入样本。
- 样本测试：手工输入、虚拟设备示例，或复用设备时序接口获取样本；对照展示原始值、结果、单位和字段校验。
- 保存：复用现有 AI 后台配置存储和当前平台登录；保存模型、映射、脚本和样本，更新时递增版本并检查并发修改。
- 样本或规则修改后，上一次测试结果失效，需重新测试。

## 演示步骤

1. 打开已保存的「输液语义转换演示」，或新建后点击「载入演示示例」。
2. 将设备编号、电量原始值、运行状态码连接到右侧对应字段。
3. 电量配置倍率 `0.1`，状态配置 `0=待机、1=运行中、2=报警`。
4. 点击「运行测试」：`865 → 86.5%`，`1 → 运行中`。
5. 在「手工脚本」从连线生成脚本，修改倍率并重新测试，验证结果实际变化。
6. 在「AI辅助脚本」填写要求，生成、查看并应用脚本，再运行测试。
7. 保存版本，返回列表重新打开。重新登录后同一平台账号仍可读取配置。

上述字段和数值均为明确标识的虚拟设备示例，不代表真实输液设备的字段单位。

## 当前范围与接口缺口

- 物模型当前随转换器保存，尚未连接独立的业务物模型目录。本次在现有前端 API 中未找到可直接使用的物模型定义接口。后续同步正式产品模型，需要模型列表和字段详情（字段标识、类型、单位、枚举、模型版本）接口。
- 目前版本号表示最新保存修订；尚无历史版本列表、回退或协议插件发布功能。
- 测试在浏览器中的 JSONata Worker 执行；尚未部署为设备接入链路的持续转换服务。
- 已接入时序查询快照，不代表实时流任务已上线。真实指标的名称和单位仍须依据正式物模型配置。
- DeepSeek 聊天生成已接通；原有知识库的向量检索仍使用原来的嵌入模型配置，本轮未改造知识库。
- 本轮没有数据库权限阻塞。新增配置复用已有表，未修改医院业务数据库。

## 身份修正

实际连续两次登录发现，平台 JWT 中的 `OrgTid` 会变化，不能作为稳定账号命名空间。已改为由受信任 SSO 地址、经过 SSO 校验的签发方和用户标识确定账号。仍然逐次向 SSO 校验令牌，并保持不同用户和签发方的数据隔离。

旧实验版本按临时登录标识保存的记录未自动归并，避免合并身份不明确的数据。本版演示转换器已在稳定身份下重新创建。
