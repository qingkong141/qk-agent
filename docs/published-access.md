# 已发布应用与智能体独立访问

在应用或智能体列表、详情页点击“发布”，选择访问方式：

- 需要登录：发布账号登录后打开独立页面。
- 免登录访问：持有专用链接的人可以使用该发布版。

发布后通过“打开”使用独立页，通过“访问链接”复制链接或调整访问方式。独立页不包含后台菜单、顶部导航或编辑工具。应用保留设计中的页面导航、变量、交互和自动刷新；智能体支持连续追问、流式回答、停止生成、图表与地图。

草稿修改不影响运行版本。应用已发布时不能重复发布，修改配置后也须先停用，再发布新版本。智能体有修改时可更新发布。停用或改成需要登录会撤销旧分享链接，再次开启免登录会生成新链接。关闭访问不能撤回访客已经看到的内容。

分享页只允许执行对应的已发布配置，不能由访客替换模型、工具或数据来源。发布账号的模型连接和数据源授权继续适用，平台凭据加密存于服务端并自动续期；平台会话彻底失效时，发布者重新登录后保存访问设置即可更新凭据。访客不会取得这些凭据。

链接使用当前浏览器的访问地址。localhost / 127.0.0.1 仅用于本机；其他电脑使用时需通过已开放的局域网地址或部署域名访问前端并复制链接。部署需支持 SPA 路由回退，以及 `/agent-api` 代理，流式响应应关闭代理缓冲。

移动应用发布页按可用宽度展开，窄屏数据表显示为记录卡片，平板使用表格。应用设计器里的手机预览仍保留手机宽度。

验证：`backend/scripts/test_publications.py`、`test_applications_api.py`、`test_agent_studio.py`；前端 `scripts/publication-smoke.cjs` 验证真实华为云模型/MCP流式对话，`scripts/publication-mobile-smoke.cjs` 验证手机、平板和桌面布局。浏览器测试使用环境变量提供登录信息，测试记录保留。
