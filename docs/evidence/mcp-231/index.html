地点结果地图展示

高德查询返回坐标后，平台展示带位置标记的真实底图。多个候选地点可分别选择，支持放大、缩小和打开高德地图；原始 JSON 保留在折叠区。

本页截图来自实际运行界面。地图图片由后台调用高德静态地图 API 获取，使用账号内已加密保存的 Web 服务 Key；浏览器不接收密钥。

当前地图预览支持地点切换和分级缩放。拖拽平移、路线等完整交互可通过“在高德地图打开”使用；嵌入 JS 动态地图需要另行提供 JS API Key 与安全密钥。
